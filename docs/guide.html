Документація Boxer

Що таке Boxer?

Boxer — це швидкий менеджер для ізольованих середовищ розробки. Він дозволяє вам легко створювати, видаляти та керувати контейнерами проєктів для різних мов програмування, не засмічуючи вашу операційну систему глобальними залежностями.

Встановлення

Перейдіть на сторінку релізів на GitHub та завантажте версію Boxer для вашої операційної системи (Windows, Linux або macOS).

Після розпакування або встановлення виконайте базове налаштування CLI в терміналі:

$ boxer setup
✅ Boxer setup complete. Please restart your terminal...

Ця команда автоматично додасть boxer до вашого PATH та налаштує необхідні alias-и для вашого терміналу (Bash, Zsh, або PowerShell).

Використання CLI

1. Створення проєкту

Щоб створити нове ізольоване середовище, використовуйте команду add:

$ boxer add MyProject --lang Python
✅ Successfully created container 'MyProject'

2. Активація середовища

Щоб активувати середовище та почати в ньому працювати, використовуйте use:

$ boxer use MyProject
🐍 Boxer: активовано Python з контейнера "MyProject"

3. Видалення проєкту

Щоб видалити проєкт та очистити його ресурси:

$ boxer remove MyProject
✅ Successfully removed container 'MyProject'

4. Перегляд проєктів

Щоб переглянути список всіх ваших контейнерів:

$ boxer list
- MyProject (Python)
- GoBackend (Go)

Використання GUI (Графічний інтерфейс)

Якщо ви віддаєте перевагу візуальному інтерфейсу, просто запустіть додаток Boxer. Графічний інтерфейс надає всі ті ж можливості, що і CLI:

  • Створення нових середовищ із вибором мови з випадаючого списку.
  • Перегляд списку існуючих проєктів у вигляді зручних карток.
  • Видалення непотрібних контейнерів в один клік.
